▦ Jadval: tugmani bosing, qator va ustun sonini kiriting — matn o'rtasiga jadval qo'yiladi. Birinchi qator avtomatik sarlavha (headers) bo'ladi, qolganlari rows. Har bir katakchani bold/italic/rang/o'lcham bilan formatlashingiz mumkin — JSON'da "type":"table", "id", "headers":[{"text":...,"align":...}] va "rows":[[{"text":...}]] ko'rinishida chiqadi.
• / 1. Ro'yxat: tugmani bosing — belgili yoki raqamli ro'yxat qo'shiladi. Har bir bandni yozib bo'lgach Enter bosing — yangi band avtomatik qo'shiladi (bo'sh bandda Enter bossangiz ro'yxatdan chiqasiz). Har bir bandni ham bold/italic/rang bilan formatlash mumkin — JSON'da "type":"list", "ordered":true/false va "items":[{"type":"text","content":[{"text":...}]}] ko'rinishida chiqadi.
Format tozalash: belgilangan qismdan bold/rang/o'lcham kabi barcha formatlarni olib tashlaydi. Agar belgilangan qism ichida Enter (qator) bo'lsa, u ham olib tashlanadi (ikki qator qo'shilib bitta bo'ladi), lekin o'sha joyga sariq ⏎ belgisi qo'yiladi — shu belgi orqali qayerda Enter olib tashlanganini topib, kerak bo'lsa qo'lda tuzatasiz (belgini belgilab o'chirib, joyiga qayta Enter bosishingiz mumkin). Bu belgi faqat tahrirlovchida ko'rinadi, JSON'ga umuman tushmaydi.

📖 Dastur qo'llanmasi va JSON hujjatlari

Dastur qanday ishlashi, har bir blok turi (matn, matematik, jadval, ro'yxat) JSON'da qanday ko'rinishda chiqishi — barchasi misollar bilan.

Dastur nima qiladi?

Bu dastur — matnni (bold, italic, tagiga/ustidan chizish, rang, o'lcham, indeks/daraja, jadval, ro'yxat kabi formatlar bilan) vizual tahrirlab, so'ng bir tugma bosish bilan structured JSON formatga aylantirish uchun mo'ljallangan. Chap tomonda yozasiz/formatlaysiz, o'ng tomonda esa tayyor JSON avtomatik chiqadi. JSON'dagi barcha kalit va qiymat nomlarini "⚙ JSON kalitlarini sozlash" tugmasi orqali o'zingizga moslab o'zgartirishingiz mumkin.

Umumiy JSON tuzilishi

Har doim hujjat uchta asosiy qismdan iborat bo'ladi: title, subtitle va blocks (bloklar ro'yxati). blocks ichida esa matn, matematik, jadval va ro'yxat bloklari ketma-ket keladi.

{ "title": "Sarlavha matni", "subtitle": "Kichik sarlavha matni", "blocks": [ ... ] }

1. Oddiy matn bloki — type: "text"

Muharrirda yozgan har bir bir xil formatdagi matn bo'lagi alohida blok bo'lib chiqadi. Format bo'lmasa, faqat type va content chiqadi.

{ "type": "text", "content": "Oddiy, formatlanmagan matn." } { "type": "text", "content": "Qalin va qizil matn.", "font_weight": "bold", "color": "#e8394d" }

Matnda Enter bossangiz, u alohida blok sifatida qator ko'chirish belgisini bildiradi:

{ "type": "text", "content": "\n" }

2. Matematik / kimyoviy blok — type: "math"

x² (daraja), H₂O (indeks) tugmalari yoki butun ifodani "𝑓(x) Math" tugmasi bilan belgilaganda shu turdagi blok chiqadi.

{ "type": "math", "content": "^{2}" } { "type": "math", "content": "_{2}" } { "type": "math", "content": "∫ x dx = x²/2 + C" }

Format kalitlari (barcha matn/matematik bloklarda ishlatiladi)

KalitQiymatNima uchun
font_weight"bold"Qalin matn
font_style"italic"Qiya matn
text_decoration"underline" / "line-through"Tagiga chizish / ustidan chizish
color"#e8394d" (hex)Matn rangi
background_color"#ffcb05" (hex)Belgilash (fon) rangi
font_size"24px"Shrift o'lchami

Bu kalitlar formatlanmagan matnda umuman chiqmaydi — faqat qo'llanilgan formatlar uchun qo'shiladi.

3. Jadval bloki — type: "table"

▦ Jadval tugmasi bilan qo'shilgan jadval shunday chiqadi: birinchi qator headers, qolgani rows. Har bir katakcha o'zi alohida obyekt bo'lib, ichida content — formatlangan matn bo'laklari (run'lar) massivi bo'ladi. Shu tufayli bitta katakchada bir so'z bold, qolgani oddiy bo'lsa ham, ikkalasi ham alohida-alohida to'g'ri chiqadi.

{ "type": "table", "id": "table_1", "headers": [ { "type": "text", "align": "left", "content": [ { "text": "Element" } ] }, { "type": "text", "align": "center", "content": [ { "text": "Belgi" } ] } ], "rows": [ [ { "type": "text", "content": [ { "text": "Kislorod", "font_weight": "bold" }, { "text": " gazi" } ] }, { "type": "text", "content": [ { "text": "O" } ] } ], [ { "type": "text", "content": [ { "text": "Vodorod" } ] }, { "type": "text", "content": [ { "text": "H" } ] } ] ] }

align ("left" / "center" / "right") faqat sarlavha (headers) katakchalarida bo'ladi — jadvaldagi ⯇/▭/⯈ tugmalari bilan boshqariladi.

4. Ro'yxat bloki — type: "list"

• yoki 1. Ro'yxat tugmasi bilan qo'shilgan bo'lim shunday chiqadi. ordered: false — belgili (bullet) ro'yxat, ordered: true — raqamli ro'yxat. Har bir band jadval katakchasi bilan bir xil tuzilishda: content ichida formatlangan run'lar massivi.

{ "type": "list", "ordered": false, "items": [ { "type": "text", "content": [ { "text": "If you're a coach, your goal might be to win a championship. " }, { "text": "Your system", "font_weight": "bold" }, { "text": " is the way you recruit players." } ] }, { "type": "text", "content": [ { "text": "If you're an entrepreneur, your goal might be to build a million-dollar business." } ] } ] }

To'liq namuna: hammasi birga

Sarlavha, oddiy matn, qalin matn, matematik ifoda, jadval va ro'yxatni o'z ichiga olgan to'liq hujjat qanday ko'rinishda chiqishi:

{ "title": "Kimyo darsligi", "subtitle": "1-bob: Elementlar", "blocks": [ { "type": "text", "content": "Suv formulasi H" }, { "type": "math", "content": "_{2}" }, { "type": "text", "content": "O bo'ladi. " }, { "type": "text", "content": "Bu muhim!", "font_weight": "bold", "color": "#e8394d" }, { "type": "text", "content": "\n" }, { "type": "table", "id": "table_1", "headers": [ { "type": "text", "align": "left", "content": [ { "text": "Element" } ] }, { "type": "text", "align": "left", "content": [ { "text": "Belgi" } ] } ], "rows": [ [ { "type": "text", "content": [ { "text": "Kislorod" } ] }, { "type": "text", "content": [ { "text": "O" } ] } ] ] }, { "type": "list", "ordered": true, "items": [ { "type": "text", "content": [ { "text": "Elementlarni yodlang" } ] }, { "type": "text", "content": [ { "text": "Formulalarni mashq qiling" } ] } ] } ] }

Muharrir tugmalari — qisqacha

  • B / I / U / S — belgilangan matnni qalin/qiya/tagiga chizilgan/ustidan chizilgan qilish. Faqat belgilangan qismga ta'sir qiladi.
  • Razmer, A (rang), ▨ (fon rangi) — belgilangan matnga shrift o'lchami/rang/fon qo'llaydi.
  • ¶ Abzas — kursor turgan joyga yangi qator (paragraf chegarasi) qo'shadi.
  • ⯇ Chap / ▭ Markaz / ⯈ O'ng — jadval sarlavha katakchasini tekislash uchun.
  • ▦ Jadval — qator/ustun sonini so'rab, jadval qo'shadi.
  • • Ro'yxat / 1. Ro'yxat — belgili yoki raqamli ro'yxat qo'shadi. Bandni yozib Enter bossangiz, yangi band avtomatik ochiladi.
  • x² / x₂ / 𝑓(x) Math — belgilangan qismni daraja/indeks yoki to'liq matematik blok qiladi.
  • Format tozalash — belgilangan qismdan barcha formatni (va agar bo'lsa, ichidagi Enter'ni ham) tozalaydi. Enter olib tashlangan joyga sariq ⏎ belgisi qo'yiladi (faqat tahrirlovchida ko'rinadi, JSON'ga tushmaydi) — shu orqali qayerda Enter olib tashlanganini topib, kerak bo'lsa qo'lda tuzatasiz.
  • 🗑 Hammasini o'chirish — butun matnni (jadval, ro'yxat bilan birga) o'chiradi, tasdiqlash so'raydi.
  • Suzuvchi panel — matn belgilaganingizda tepada chiqadi, bir xil tugmalarning kichraytirilgan varianti, shu jumladan ✕ (format tozalash) va 🗑 (belgilangan matnni butunlay o'chirish).

JSON kalit/qiymat nomlarini o'zgartirish

"⚙ JSON kalitlarini sozlash" tugmasi orqali title, content, font_weight kabi barcha kalit nomlarini, shuningdek "bold", "table" kabi qiymat nomlarini o'zingiz ishlatadigan tizimga moslab o'zgartirishingiz mumkin. Bo'sh qoldirilgan maydonlar uchun standart nom ishlatiladi.
